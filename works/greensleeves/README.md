## 결단 자료 (s336 · 코튼 *시대 새로움* axis 정합)

- **시대 선정 path** = 미개척 시대 (르네상스 / 고전 / 낭만) 점검 cycle. 짐노페디(사티 1888)를 낭만 말기로 분류 → 낭만 터치한 셈 → **르네상스 vs 고전 2파전** → 코튼 **르네상스 그린슬리브즈** 결단.
- **선정 사유** = 르네상스는 *아카펠라의 본향* (성악 polyphony가 원래 주인공인 시대) · 지금 4곡 중 시대 점프 가장 큼 · 모달(도리안) 화성 = 완전 신규 axis · 멜로디 인지도 세계 최상급 (=「What Child Is This」).
- **분량** = 통째 (짧은 곡 · 발췌 없음 · 짐노페디·비발디·조플린 family 정합 = 자연 짧은 곡 통째 transcription default).
- **명화** = Ditchley Portrait of Elizabeth I (Gheeraerts, c.1592) · csv row 101 자료 · 엘리자베스 시대 = 그린슬리브즈 동시대 정합 강.
- **score** = candidates_opus 편곡 후보 4종 (`그린슬리브스_1~4.pdf` · 31KB~4MB · 편곡/에디션 제각각) · 코튼 pick 자리. IMSLP `https://imslp.org/wiki/Greensleeves_(Traditional)` PD 강.

## 르네상스·아카펠라 양식 신규 challenge 자료

이전 세 곡과 결 다른 자료들 (시대 점프 axis 정합):

- **모달 화성** — 그린슬리브즈는 modal (도리안/에올리안 · 특유의 raised 6th false-relation 양식) · tonal 양식 (바로크/고전/ragtime) 이탈 = 완전 신규 화성 세계.
- **르네상스 consort 텍스쳐** — 성악 polyphony가 native인 시대 · SATB consort 양식 미쿠 stacking 자연 path (이 시대 자체가 아카펠라).
- **가사 axis (NEW · 시리즈 첫 성악 텍스트 곡 확정 · s336 코튼 결단)** — 이전 3곡은 다 기악 원곡 (짐노페디 피아노 / 비발디 협주곡 / 조플린 rag · 모음·humming default). 그린슬리브즈는 **실제 영어 가사 사용 확정** (*"Alas, my love, you do me wrong..."* · 16세기 전통 가사 PD). 시리즈 *첫 성악 텍스트* 곡 = 정체성 분기점. 가사 선정/절 분배 = 코튼 직접. 신규 challenge = **V6 영어 딕션 통제** (이전 일본어/모음 Miku 이탈 axis).
- **strophic form** — verse + refrain 양식 · 절 반복 분배 (몇 절 / 기악 간주 / vocal) = form 결단 자리.
