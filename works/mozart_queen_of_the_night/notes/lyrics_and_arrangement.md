# 밤의 여왕 아리아 — 가사 · 발음 · 편곡 설계

> ⑫ Mozart, *Der Hölle Rache kocht in meinem Herzen* (Die Zauberflöte K.620, Act II No. 14, 1791)
> = "밤의 여왕 아리아" 중 **2막** (그 유명한 F6 콜로라투라 · 코튼 확정 2026-06-15). 1막 *O zittre nicht* 아님.
> 가사 방향 = **(가) 독일어 원어** (코튼 결정 2026-06-15)
> 폴백 = 발음 품질 미달 시 **(나) 보칼리제(모음 Ah)**. 게이트에서 분리 판정. (단 헨델 이탈리아어 통과 선례 있음)
> 곡 성격 = D단조 · **Allegro assai**(빠르고 격렬) · 분노/복수 = **시리즈 첫 극적·격렬 캐릭터**. 길이 ≈ 2:55~3:00 (전 작품 대비 짧고 압축적).

## 1. 가사 원문 (PD · Emanuel Schikaneder 대본 1791)

**1부 (declamatory · 분노의 선언)**
```
Der Hölle Rache kocht in meinem Herzen,
Tod und Verzweiflung flammet um mich her!
Fühlt nicht durch dich Sarastro Todesschmerzen,
So bist du meine Tochter nimmermehr.
```
→ 이어 **콜로라투라 1** (멜리스마 · 상승 · F6 도달)

**2부 (저주 · 격앙)**
```
Verstoßen sei auf ewig, verlassen sei auf ewig,
Zertrümmert sei'n auf ewig alle Bande der Natur,
```
→ **콜로라투라 2 = 시그너처 스타카토 F6 패시지 2회** (이 곡의 얼굴 · 도약 스타카토)
```
Wenn nicht durch dich Sarastro wird erblassen!
```

**종결 (맹세)**
```
Hört, Hört, Hört, Rachegötter,
Hört der Mutter Schwur!
```

### 직역 (참고 · 영상 description 아님)
> 지옥의 복수가 내 마음 속에 끓어오르고, 죽음과 절망이 내 주위에 불타오른다!
> 사라스트로가 너의 손에 죽음의 고통을 느끼지 않는다면, 너는 더 이상 내 딸이 아니다.
> 영원히 버림받고, 영원히 버려지고, 영원히 부서져라, 자연의 모든 인연이여,
> 네가 사라스트로를 쓰러뜨리지 않는다면! 들어라, 들어라, 들어라, 복수의 신들이여, 어머니의 맹세를!

## 2. V6 발음 음소 가이드 (독일어 · **시리즈 첫 독일어**)

⚠️ 이탈리아어(헨델)보다 난도 ↑. 핵심 난점 = **움라우트(ö/ü)** · **ch 두 종류(ich/ach laut)** · **z=[ts]** · **어말 무성화** · **독일어 r**. 단 **콜로라투라 구간은 사실상 모음 멜리스마**라 발음 난점과 분리됨(아래 §3 참조).

**발음 게이트 체크포인트** (V6 입력 후 코튼 청취 · 난점 우선순위):
1. **ö/ü** (Hölle·Fühlt·Hört·Götter·Zertrümmert) 가 단순 e/u로 무너지지 않는가 (예상 약점 1순위)
2. **ich-laut [ç]** (mich·nicht·dich·ewig·-ig) 가 k나 sh로 흐려지지 않는가
3. **z=[ts]** (Herzen·Verzweiflung·Zertrümmert) 와 **어두 st=ʃt** (Verstoßen)
4. 어말 무성화(Tod·und·wird) + 독일어 r 처리
→ 1~2 항목이 심하게 무너지면 **(나) 보칼리제 폴백** 검토 (단 콜로라투라는 어차피 모음이라 폴백 시에도 곡 정체성 유지됨).

## 3. ★★ 핵심 게이트 = F6 콜로라투라 (이 곡 성패 축)

이 곡의 정체성 = **하이 F6** (고음 C 위의 F · ~1397Hz) 까지 치솟는 **스타카토 도약 콜로라투라**. 발음 게이트와 **별개의, 더 중요한 축**.

- **콜로라투라 구간은 텍스트가 아니라 모음 멜리스마**(원곡도 한 모음 위에서 굴림) → 발음 부담은 낮고, **음정 정확도 + 스타카토 분절 + V6 극고음역 음질**이 전부.
- 점검 항목:
  1. **F6 음질** — V6 미쿠가 그 음역에서 얇아지거나 깨지지/기계적이지 않은가 (헨델 F6 아닌 소프라노 영역과 차원이 다름 · V6 상한 한계 실측 필요)
  2. **스타카토 분절** — 빠른 도약 스타카토가 뭉개지지 않고 또렷이 튀는가 (note별 짧은 길이 + 간격 입력)
  3. **음정 정확** — 빠른 콜로라투라 런의 각 음이 정확한가 (레가토 곡보다 입력 정밀도 요구 ↑)
- ⚠️ **F6는 양보 불가 = 곡의 얼굴.** 만약 V6가 F6에서 심하게 무너지면 → (a) V6 음색뱅크/파라미터 조정 시도 (b) 최후수단 고려해야 하나 **이조(transpose down)는 곡 정체성 파괴**라 강력 비추 → 음악 단계 첫 실험으로 F6 클린 여부 이진 판정부터.

## 4. 편곡 · 성부 설계 (잠정 — 청취 게이트 전)

원곡 = **콜로라투라 소프라노 + 관현악**(현·목관·금관·팀파니), **D단조 · Allegro assai · 격앙·구동적**. 정서 = 분노·복수의 광기.

| 성부 | 원곡 라인 | 미쿠 처리 | 텍스트 |
|---|---|---|---|
| **Lead** | 밤의 여왕 콜로라투라 소프라노 | lead_miku | **독일어 가사 full + F6 콜로라투라** |
| **Mid** | 현·목관 화성 (트레몰로/구동 리듬) | mid (다성) | 모음 Ah/Oo · **격앙된 분절·구동감** |
| **Low** | 첼로·콘트라베이스·바순 베이스 | low_oo | 모음 Oo |
| (accent) | 금관·팀파니 강세 | (선택) 짧은 Ah 강세 | 분노 악센트 강조용 |

**설계 의도**
- 가사는 **Lead만** — 콜로라투라 텍스트 명료성 + 다성 혼탁 회피 (헨델 선례 정합).
- ⚠️ **캐릭터 = 헨델/사탕요정과 정반대.** 느린 레가토·intimate가 아니라 **격렬·구동·각진 분절**. 반주(Mid/Low)가 잔잔한 패드면 곡이 죽음 → **현 트레몰로/반복음의 긴장감**을 모음으로 어떻게 살릴지가 편곡 핵심.
- 콜로라투라 구간 = 원곡처럼 **반주가 얇아지거나 스타카토 화음으로 점을 찍어** Lead의 곡예를 띄움.
- 마스터링 = LRA(다이내믹) 보존 + 격렬곡이라 음량 밴드는 **활기곡 쪽(-16대, 하이든 선례)** 검토 (intimate -17대 아님 가능).

**길이 예상** = ≈ 2:55~3:00 (Allegro assai · 반복 적음 · 시리즈 최단 후보).
