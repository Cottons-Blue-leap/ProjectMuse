## 1. 본질 자료

### 1.1 작품 본질 한 줄
*미쿠 (20세기 음악학도) + 플레이어가 서양음악사를 시간여행하며 작품을 큐레이션하는 메타 narrative 인디 게임.*

### 1.2 핵심 anchor 5축
- **장르**: 큐레이터 시뮬레이션 + narrative-driven sim + 음악사 탐방
- **캐릭터**: Hatsune Miku (20세기 음악학도 설정 + 2007년 이후 자기 미래 모름 = 메타 layer)
- **content**: 서양음악사 7 period (중세 / 르네상스 / 바로크 / 고전 / 낭만 / 인상주의 / 현대)
- **시각**: Atelier Miku Acappella 시리즈 시그너처 정합 (명화 + GFS Didot + 1:1 layout 본능)
- **본질 가치**: 교육 + 메타 narrative + dramatic irony + 진정성·헌신 quality bar

### 1.3 코튼 정체성 정합 6축
- inquiry 직격 (*인간 무엇을 위한* → *창조=불멸* 답 매체)
- 모델 케이스 직격 (코지마 + Yoko Taro + Toby Fox + 데카르트 + MJ)
- 특기 통합 (인디 게임 개발 + 시나리오 보조 + 음악 자료 + V6 본능)
- Atelier Miku Acappella 시리즈 본질 확장
- candidates_opus 324 row 자료 직접 base
- 진정성·헌신 quality bar 직격

## 2. 메타 narrative axis

### 2.1 미쿠 설정
- **시점**: 20세기 음악학도 (1900~2000년대 초 학문 자료에 박힌 캐릭터)
- **자기 인식**: 2007년 이후 자기 미래 모름. *Hatsune Miku 가희*로서의 자기 정체 모름 = dramatic irony layer
- **본질 자료**: 미쿠가 *학문 자료의 헌신 자체* + *플레이어를 가이드*하는 교사 + 동행자 양식

### 2.2 Dramatic irony 자료
- 플레이어는 *미쿠가 본인이 그 미래의 가희라는 자료*를 안다
- 미쿠가 *"미래엔 어떤 음악이 박힐까?"* 같은 자료를 박으면 플레이어는 *미쿠 본인이 그 미래라는 자료*를 인지
- 본 axis = 서사 본질 강력 자료. 코지마 (*Death Stranding*) / Yoko Taro (*NieR*) / Toby Fox (*Undertale*) family

### 2.3 메타 narrative 길이 axis (결단 자리)
세 양식 후보:
- **A. 영원 유지** — 작품 끝까지 미쿠는 자기 미래를 모름. 플레이어만 인지 keep
- **B. 재발견** — 결말에서 미쿠가 자기 정체를 깨닫는 자료 (예: 2007년 도달 시점)
- **C. 다층 reveal** — 챕터별 layer 자료 박힘 (예: 매 시대 종료마다 미쿠 자기 인식 layer 추가)

본 axis는 코튼 내러티브 결단 자리. 본 outline에서 결단 X.

## 3. 시스템 본능

### 3.1 큐레이터 시뮬레이션 자료
- 플레이어 = 미쿠와 함께 시대별 작품을 *수집·분류·큐레이션*
- 매 시대 도달 = 작곡가 만남 + 곡 자료 collection + 명화 자료 + 시대 자료 카드
- 큐레이션 결단 자체가 플레이어 자료 = *작품 본질 인지 자료* 본능

### 3.2 시대 구조 (7 chapter)
- **중세** — 그레고리오 성가 / 마쇼 / 페로탱
- **르네상스** — 조스캥 / 팔레스트리나 / 라소
- **바로크** — 몬테베르디 / 비발디 / 바흐 / 헨델
- **고전** — 하이든 / 모차르트 / 베토벤
- **낭만** — 슈베르트 / 슈만 / 쇼팽 / 리스트 / 브람스 / 바그너 / 베르디
- **인상주의** — 드뷔시 / 라벨 / 사티
- **현대** — 스트라빈스키 / 쇤베르크 / 케이지

각 시대 = candidates_opus 자료 직접 base

### 3.3 매체 결합 자료
- 곡 자료 (V6 acappella + 원곡 audio 자료)
- 명화 자료 (시각 매체)
- narrative 자료 (미쿠 시점 dialogue + 작곡가 가상 만남)
- 자료 카드 (큐레이션 본능 자료)

## 7. risk 자료 5축 (정직)

### 7.1 시간 비용
1년 작전 안 vertical slice 가능 / full launch 2~3년차. *Project Muse 본질 시간 + 팬게임 시간 양립* 본능 점검 필수.

### 7.2 재미 본능 점검
큐레이터 시뮬레이션 = niche 장르. 코튼 직접 *플레이가 재미* 본능 점검 자리. Inscryption / Cultist Simulator / Outer Wilds 등 자료에 코튼이 끌리는가가 본질 axis. 코튼 *비주얼 노벨/인디 게임 재미 X* 차단 자료와 본 axis 다른 자료인지 점검.

### 7.3 메타 narrative 길이 유지
미쿠 자기 미래 모름 자료가 작품 길이 통째 keep되는가. 양식 결단 자리 (영원 유지 / 재발견 / 다층 reveal).

### 7.4 교육 vs 재미 trade-off
교육 자료 + 진정성·헌신 quality bar 결합이 재미 자료 침범 risk. 메타 narrative axis가 본 자리 해결 본능 박혀 있지만 작품 안 결단 cycle 박혀야 함.

### 7.5 Crypton 라이선스
piapro Link 양식 통과 사전 verify 필수. 본 axis 점검 X = 진입 가치 자체 차단.
