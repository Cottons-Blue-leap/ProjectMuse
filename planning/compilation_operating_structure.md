## 2. 합본 vs 재생목록 판단 룰 (핵심)

둘은 경쟁이 아니라 **다른 일을 한다.**
- **재생목록** = 비용 0 · 새 영상 0 · watch-time을 *개별 영상*에 적립(개별 알고리즘 신호 강화) · 이미 온 시청자 회유. 약점: 노출/검색이 약해 신규 진입을 거의 못 만듦.
- **합본** = 새 단일 영상 = 새 노출 표면 + 새 썸네일/제목으로 *새 검색어*를 잡는 **신규 진입점**. 약점: 제작 비용 + 중복/잠식 위험.

> **판단 기준 (3박자 규율 · 2026-06-12 개정):** 합본 영상은 셋이 **모두** 설 때만. 하나라도 빠지면 재생목록.
> 1. **규모** — 완성본 **15분 이상** (lean-back 연속재생 가치의 정량 floor · 코튼 LOCK 2026-06-12). 15분 미만 = 무조건 재생목록(완결성 무관).
> 2. **증분 검색** — 개별 영상이 *아직 안 잡은* 새 검색 수요를 잡나. (봄 3악장 합본은 "비발디 사계 봄" 수요를 봄1 개별이 이미 흡수 → 증분 0.)
> 3. **완결성** — 하나의 작품/사이클(suite·전곡)로 닫히나.
> 15분은 *필요조건(floor)*이지 충분조건 아님 — 길어도 증분·완결성 없으면 재생목록.

적용:
- "사계 봄 1~3악장" → **재생목록** (~10분 < 15분 floor + 증분 0[봄1이 검색 흡수]). 개별 3악장 + "사계" 재생목록으로 충분. ★ 2026-06-12 정정 — 구 "합본 ✅" 폐기(코튼 "너무 쉬워·영상만 많아짐" 적발).
- "사계 전곡" (12악장 ~40분) → 합본 ✅✅ (거대 검색어 + 규모·완결성)
- "호두까기 모음곡 전곡" (8곡 ~20분+) → 합본 ✅ (단일 검색어 + 15분 통과 + suite 완결)
- "작곡가별"(쇼팽 모음·바로크 모음) → 재생목록 ❌ (느슨 · 고유 검색수요/완결성 없음)
- "쇼팽 녹턴집(21곡)" → 재생목록. 합본 한다면 Quest가 아니라 **"쇼팽 녹턴 베스트" 선별 합본**(Flagship/Evergreen 성격). Quest = 끝선 명확한 완결 사이클(호두까기·사계)에만.
- "전곡 쇼케이스(미쿠가 부른 전곡 Vol.1)" → **재생목록**. 느슨한 전곡 묶음·완결성 없음 → 이미 `Miku Non Stop A Cappella` 재생목록이 lean-back 연속재생 역할 수행. 합본 X (2026-06-11 코튼 적발 · MOKA 초기 추천 자가 철회). 선별 베스트가 필요하면 Flagship 10선이 담당.

**다악장 운영(코튼 결정 2026-06-12):** 개별 악장 + 합본 둘 다(사계 봄 1악장 이미 개별 발행과 정합). 잠식 완화 = 합본을 **"전곡 완성 보너스"로 마지막에** 얹고(= 잠식이 아니라 완성 마일스톤), 개별↔합본 카드/설명 상호링크로 트래픽 환류.

## 3.6 연재 운영 — Quest를 *보이게* 띄운다 (서사 표면 · 2026-06-12 신설)

> 도전과제 보드(§3.5)는 *내부* 자산. Gemini 서사 효과("다음 편을 기다리게 + 구독 전환")는 Quest를 **외부 표면에 명시적 '연재'로 노출**할 때 비로소 발생. 추가 제작비 0 — 기존 보드를 표면에 드러내기만.

- **첫 연재 깃발 = 호두까기 모음곡 전곡** (8곡 · 겨울 시즌 · 끝선이 멀어 "긴 카운트다운" 서사가 진짜로 섬). ※사계 봄(3곡)은 끝선이 짧아 연재 서사가 안 서서 탈락.
- **연재 표면 3 (비용 0):**
  1. **고정댓글 진행 게이지** — 매 편: `🤍 호두까기 전곡 프로젝트 — N/8. 다음은 [곡].` (지금은 "다음 곡 예고" 한 줄로만 새던 걸 연재 게이지로 격상)
  2. **커뮤니티탭** — 카운트다운 / "다음 곡 투표" 가벼운 참여
  3. **개별 ↔ 피날레 합본 상호링크**
- **피날레 = 마지막 곡 발행 시 "호두까기 전곡" 합본 동시 발행** = 연재 클라이맥스 + 새 진입점(§2 3박자 통과: ~20분+·단일검색어·suite완결). 12월 시즌 정렬.
- **양식 검증**: 연재 운영(게이지·표면)은 매 편마다 점진 검증 — *합본 영상을 따로 파일럿할 필요 없음*(과거 "사계 봄으로 양식 테스트" 발상 폐기).

## 4. 선곡 전략 시사점 (빈 슬롯이 다음 곡을 가리킨다)

멀티슬롯 효율로 다음 편곡 후보를 줄 세우면:

1. **비발디 봄 2·3악장** = 사계 *전곡* Quest 진행(1/12→3/12) + 봄/희망 무드 + 바로크 = **3슬롯**(개별 발행). ※봄만의 합본은 폐기(§2 15분 미달) — 멀티슬롯 효율 자체는 여전히 높음.
2. **꽃의 왈츠(호두까기)** = 호두까기 Quest + 차이콥스키 + **겨울 무드(현재 1곡뿐)** + Flagship 후보 = **4슬롯**. 가장 빈약한 겨울 무드를 메우는 최고 효율.
3. **겨울 보강** = 겨울 무드가 ⑧ 단 1곡 → 비발디 사계 겨울, 차이콥스키 겨울 곡 등이 Evergreen "겨울" 시리즈를 빠르게 임계로.

> 원칙: "다음에 뭘 편곡하지?" → "**어느 빈 슬롯을 메우면 가장 많이 채워지나?**"

## 5. 가동 로드맵 (카탈로그 규모별)

- **지금(~10곡)**: **호두까기 '연재' 착수**(첫 연재 깃발 · §3.6) + 곡 누적 ← 동기부여 가장 확실. (전곡 쇼케이스·사계 봄 합본 = 폐기, 재생목록이 담당)
- **20~30곡**: **Evergreen 감정 시리즈 #1** 발행(임계 도달) — 초기엔 감정축 2~3개만(밤·희망·애상) 집중해 빨리 #1, 이후 분화
- **연말/30곡+**: **Flagship "올해의 10선"** 가동(선정에 변별력 생김) — 제작자 축은 곡별 한 줄 코멘터리(코튼 auteur voice), 시청자 축은 조회/좋아요 실측
