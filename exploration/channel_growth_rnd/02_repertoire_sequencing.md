## 1. 왜 인지도인가 — 4개 신호 수렴

| 신호 | 출처 | 함의 |
|---|---|---|
| 친숙곡이 차가운 시청자도 더 붙듦 | 진단 발견3 (조플린 40.85% 유지) | 인지도 = 유지율 |
| 유입 검색은 전부 보컬로이드+정확곡명 | 진단 발견6 (salut/ah vous) | 인지도 = 검색 발견성 |
| 별명>>카탈로그번호, 대중이 치는 문자열 | 리서치 B | *별명 강한 곡*일수록 검색 잡힘 |
| "누구나 아는 그 부분" = 쇼츠 1순위 훅 | 리서치 C | 인지 악구 = 쇼츠 top-of-funnel |
| 추천은 *기존 클러스터 옆*에 붙음 (우린 8영상=클러스터 없음) | 리서치 A | 유명곡 = 거대 클러스터에 attach 빠름 |

→ 인지도는 **웜 CTR · 검색 · 쇼츠 · 추천 클러스터 4개 표면을 동시에** 들어올린다. 살롱 소품(엘가 CTR 1.1%)·니치 곡은 이 4개가 다 약하다.

**시그너처 훅 정합** (리서치 A): *"악기 없이, 전곡을, N명의 미쿠가"*. 이 훅이 가장 빛나는 건 **청중이 원곡을 이미 아는** 곡 — 비교 대상이 머릿속에 있어야 "오케스트라를 목소리로 재현"의 경이가 산다.

## 2. 선택 렌즈 (6축 스코어)

곡 후보를 볼 때 점검할 축. 결단 공식 아닌 *대화용 렌즈*:

1. **인지도** — 멜로디가 즉시 식별되나 (웜 CTR·쇼츠 훅)
2. **검색명 강도** — 강한 별명/incipit이 있나 ("Moonlight"·"Canon in D" 강 / "Op.11-5" 약)
3. **아카펠라 적합성** ★게이트 — 멜로디 전면·보컬 레이어로 사는가 ([[feedback-muse-arrangement-listen-gate]] · 이 축은 **veto 권한**)
4. **시대 슬롯** — 시대 재생목록 균형/충원
5. **명화 가용성** — 미사용 화가의 PD 명화 매치 ([[ballet-subfamily-convention]] 화가1곡1회)
6. **쇼츠 훅 명료성** — 18~25s "그 부분"이 또렷한가

**3번이 1번을 이긴다**: 아무리 유명해도 아카펠라로 안 살면 탈락. 우리 medium은 무반주 보컬 — *멜로디 전면+지속음* 곡이 본질 적합(엘가·녹턴·캐논이 그래서 성공).

## 4. "인지도 웨이브" 후보 숏리스트 (다음 6곡 자리)

벤치 S tier 중 **인지도 최상 + 아카펠라 적합 + 브랜드(차분·고크래프트) 정합** 교집합. *제안이지 잠금 아님 — 각 곡 V6 청취 게이트 통과 필수*.

| 곡 | 시대 | 인지도 | 아카펠라 적합 근거 | 쇼츠 훅 |
|---|---|---|---|---|
| **베토벤 — 환희의 송가** | 고전 | 최상 | **원곡이 합창** = N-Miku 시그너처의 정점. 찬가 구조 | "다-다-다-다" 메인 테마 |
| **바흐 — G선상의 아리아** | 바로크 | 최상 | **지속 긴 선율** = 보컬 최적(녹턴 family) | 오프닝 상행 |
| **슈베르트 — 아베 마리아** | 낭만 | 최상 | **원곡이 성악곡** = 무반주 보컬 직결 | "Ave Maria" 첫 구 |
| **드뷔시 — 달빛 (Clair de Lune)** | 20세기 | 최상 | 흐르는 선율·차분 = 브랜드 정합·20c 충원 | 메인 테마 |
| **베토벤 — 엘리제를 위하여** | 고전 | 최상 | 가벼운 단선율 = 명료 | "미-레#-미-레#-미" |
| **베토벤 — 월광 소나타 1악장** | 고전 | 최상 | 차분·삼연음 내성부 = 보컬 레이어 (적합 中) | 메인 멜로디 |

**왜 이 6곡** (정합 논리):
- 6곡 다 **검색명 최상**(전부 강한 별명/incipit) + 차분→브랜드 정합 + 무반주 보컬 적합.
- **환희의 송가·아베 마리아**는 *원곡이 성악·합창* → N-Miku 시그너처가 가장 자연스럽게 빛나는 자리. 우선순위 후보.
- **G선상의 아리아·달빛**은 녹턴(유지율 47.78%)과 같은 "차분 멜로디" 클러스터 → 추천 attach 가속(리서치 A 추론).
- 시대 충원: 고전 +3·바로크 +1·낭만 +1·20c +1 = 낭만 편중 완화 + 균형. 르네상스는 의도적 보류(§6).

## 6. 전략 긴장 (코튼 결단 자리 · 양면 제시)

**긴장 1 — 인지도 편향 vs 시대 완성주의**
재생목록 시대 균형(르네상스 공백)을 메우려면 르네상스 곡이 필요한데, 르네상스는 그린슬리브즈(A) 외 인지도·검색성 빈약. → **권장 방향**: 시대 완성주의는 *약한 동력*. 르네상스는 인지도 웨이브가 자리 잡은 *후* 그린슬리브즈 1곡으로 상징적 충원 정도. 지금 르네상스에 슬롯 쓰는 건 발견성 손해.

**긴장 2 — "후크 명곡 소진" 속도** ★코튼 핵심 지적 (s402)
초유명 곡은 유한하다(S 92 중 *즉시인지* 부분집합 ≈30-40). 인지도 우선은 그 자체로 **지속가능한 엔진이 아니다** — 코튼 정확.
→ **재프레임 (s402 합의)**: 인지도는 *엔진이 아니라 콜드스타트 가속제*. 거기 전략을 거는 게 아님.
- **안 닳는 엔진 = 시그너처 자체**(전곡을·무반주로·N명의 미쿠). 신선함의 출처가 "유명한 곡"이 아니라 "이 곡을 32미쿠 아카펠라로 들어본 적 없음" → *medium이 novelty*. 중간 인지도 곡도 우리 산출물로선 100% 신선. 즉 닳는 건 곡이 아니라 *최상위 인지도*뿐.
- 그 최상위 인지도는 **콜드스타트일 때 가장 값나가고, 따뜻한 표면(구독·클러스터·검색) 쌓이면 덜 필요**해진다. 게다가 한 번 발행한 유명곡은 *영구* 검색·클러스터 자산 → 나중 중간곡을 발견되게 함 = **소비가 아니라 투자**.
- **스펜드 커브**: 인지도는 *지금* 몰아 쓰는 게 옳고(가장 값날 때 + 기반 복리), 채널이 크면 무게가 자연히 craft·차별화(긴장3)로 글라이드. 카탈로그 8편 = 리서치 C "얇은 카탈로그" 병목 → 지금 인지도곡으로 기반 자산 빠르게 쌓기.

**긴장 3 — 검증된 친숙도 vs 발견의 신선함**
전부 초유명곡만 내면 "또 그 곡" 피로 + 차별화 약화. → 인지도 웨이브(기반) + 가끔 *덜 유명하나 아카펠라로 경이로운* 곡(차별화·작품성)을 교차. 엘가·보케리니가 후자 자리. 균형은 코튼 큐레이션.

## 7. 국가 시리즈 = 별도 sub-series 실험 (분리 제언)

s401 D buffer 등재된 국가 6곡(라마르세예즈·황제찬가·마멜리·별이빛나는깃발·God Save the King·기미가요)은 **인지도 웨이브와 다른 트랙**으로 보는 게 정합:
- 포지셔닝 분리 = 별도 재생목록("Anthems, A Cappella" 류) + 검색 클러스터(국가명 검색)가 클래식 클러스터와 다름.
- 리스크 = *정치색 axis*(s392 Battle Hymn 제외 선례). 국가는 민감 — 순수 PD·고인지도·중립 프레이밍 keep.
- 기회 = 국가는 인지도·검색 강 + 합창 적합(N-Miku) + 다국 l10n 자연 정합.
- → R&D 제언: 국가 시리즈는 *클래식 본편이 안착한 뒤* 별도 미니 시리즈로 파일럿. 지금 본편 슬롯에 섞지 말 것.

## 8. 정직 플래그 — 내가 *주장하지 않는* 것

- 인지도는 **편향(bias)이지 보장 아님**. 표본 작음(영상별 N 수십). "유명곡 내면 뜬다"가 아니라 "통제가능 4표면을 동시에 유리하게 한다".
- **아카펠라 게이트가 어떤 픽도 veto 가능** — 청취 전엔 적합 "추정"일 뿐. §4 "적합 근거"는 가설.
- 추천 클러스터 attach 가속(§4)은 [추론], YouTube 미확인.
- 명화 가용성(축5)은 곡 확정 후 per-work 게이트 — 여기서 미해결.
- 곡 선택 = 코튼 고유 권한. 이 문서는 *데이터 통역*이지 셋리스트 강요 아님.
