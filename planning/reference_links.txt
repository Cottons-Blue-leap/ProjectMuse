Project Muse Reference Links
============================

Purpose
-------
This file collects useful reference links for the Miku/VOCALOID acappella
project. Treat these as leads, not final proof. For any released work, verify
rights again in works/<piece>/rights/rights-log.md.


VOCALOID Acappella / Choir Precedents
-------------------------------------

VOCALOID acappella choir album: "Bokapera - Theme: Beta" / Magical Album Vol.16
https://www.ktrmagician.com/ma/html/ma_16.html
Notes:
- Page describes a VOCALOID acappella choir collection.
- Includes SATB role assignments using Hatsune Miku and other VOCALOIDs.
- Some tracks appear to use Hatsune Miku for all SATB parts.

K.H.Editor: Dragon Quest Overture x Hatsune Miku vocalo-acappella
https://kenkihikage.com/vocalo-acappella-dq1op/
Notes:
- Defines "vocalo-acappella" as music made only with VOCALOID voices.
- States the project used only Hatsune Miku voice.
- Mentions Miku V4X Original and Soft, which is useful for our Miku-only tests.

Hatsune Miku Wiki tag list
https://w.atwiki.jp/hmiku/pages/78.html
Notes:
- Contains tags for VOCALOID choir, all-Miku works, Hatsune Miku choir series,
  Miku chorus, and Miku-Miku choir.
- Useful for searching older Japanese/NicoNico choir and all-Miku precedents.

KARENT: Lip Sync Records artist page
https://karent.jp/artist/pp000614
Notes:
- Lists several Hatsune Miku tracks with "acapella/accapella" versions, such as
  STAR GUITAR, EMAIL, Story Rider, and NEXT ON YOU.
- These may be isolated vocal/acapella releases rather than arranged acappella,
  so treat them as terminology precedent, not direct musical precedent.

Project Positioning Notes
-------------------------

Avoid saying:
- "world first"
- "first VOCALOID acappella"
- "first Miku-only acappella"

Safer positioning:
- "Miku-centered classical acappella experiment"
- "classical vocalise arranged for Miku-only acappella"
- "a workflow for designing Hatsune Miku as a virtual acappella choir"
- "public-domain classical music reimagined as Miku-centered vocal synthesis"


World-Loved Classics Source Signals
-----------------------------------

Classic FM Hall of Fame
https://www.classicfm.com/radio/hall-of-fame/
Notes:
- Classic FM describes this as the world's biggest classical music chart.
- Useful as a broad popularity signal, not a rights source.

Classic FM Hall of Fame 2026 Top 10 article
https://www.classicfm.com/radio/hall-of-fame/karl-jenkins-armed-man-number-one/
Notes:
- Useful for current popularity context.
- Many high-ranking works are modern or religious, so do not automatically
  treat popularity as project fit.

Classical California Ultimate 101 (2025)
https://assets.ctfassets.net/8usdt07j8s00/3MCejR3BVT77IJZr8Li0sj/dff9d4c42bf59affb8cc01ce3b08327e/Classical_California-s_Ultimate_101__2025_.pdf
Notes:
- Useful contemporary public-radio popularity snapshot.
- Includes several Project Muse candidates such as Clair de lune, Swan Lake,
  The Four Seasons, Canon in D, The Swan, Gymnopedies, and Vocalise.

BBC Music Magazine: 15 famous classical music moments
https://www.classical-music.com/features/works/famous-classical-music-moments
Notes:
- Useful for identifying famous excerpts inside larger works, such as Bach's
  Air from Orchestral Suite No. 3.
