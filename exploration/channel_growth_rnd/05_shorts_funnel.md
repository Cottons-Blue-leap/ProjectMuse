## 0. 한 줄

**쇼츠는 우리가 *직접 여는* 유일한 새 콜드 유입구다 — 통제 못 하는 추천 노출(0.6%)과 달리.** 단 ① 쇼츠→롱폼 퍼널은 **자동이 아니라 수동 설계**해야 하고 ② **off-brand 기믹은 금지**(우리가 이기고 있는 유지율 신호를 희석) ③ 카탈로그 8편 = 쇼츠가 *증폭할 자산*이 아직 얇음. → **온브랜드 "그 부분" 루프 1편/릴리즈를 실험으로**, raw 뷰 아닌 *퍼널 전환*을 측정.

---

## 1. 왜 쇼츠인가 (발견1·2 정합)

- 우리 최대 노출(추천 80%)은 CTR 0.6%·통제불가. 쇼츠는 *우리가 만든* top-of-funnel.
- 쇼츠 = 작은 채널 콜드스타트 최효율 표면(리서치 A·C). 12구독엔 수천뷰도 현 노출의 큰 배수.
- 쇼츠 알고리즘 = **별도 시스템**(완성률 최적화). 롱폼 CTR 바닥과 무관하게 독립 평가.

## 2. 냉정한 전제 (리서치 C · 가장 중요)

- **퍼널 자동 아님**: 쇼츠 피드↔롱폼 추천 분리. 바이럴 쇼츠가 롱폼 자동노출 X. → *다리를 손으로*(CTA·고정댓글 링크·채널 레이아웃).
- 전환: 롱폼이 시청자당 **~3~4배** 구독 우위. 쇼츠 = 발견이지 구독 머신 아님. "쇼츠 바이럴 → 채널 폭발" 기대 X. 승리조건 = *콜드지만 큰 풀에서 도달 + 소수 % 롱폼 클릭 + 그 일부 구독*.
- **카탈로그 병목**: 8편 = 쇼츠가 시청자를 *얇은 카탈로그*에 떨굼. → 쇼츠는 카탈로그를 증폭하지 대체 못 함.

## 3. 포맷 — 온브랜드 "그 부분" 루프 (단일 최고레버)

리서치 C 플레이북을 Muse 자산으로 변용. 우리 2대 유니크 자산(*가장 인지되는 PD 멜로디* + *큐레이트된 명화*)을 쓰고 off-brand 청중을 안 들임:

```
길이 18~25s
0:00 (첫 1.5s)  인지 악구 콜드오픈 — 인트로·로고 X (첫 3초 50~60% 이탈)
비주얼          9:16 프레임 · 명화 중앙 + 보완 블러필(레터박스 미감 유지)
                · 디테일→전체 느린 reveal, 음악 swell에 싱크
텍스트(번인)    2줄: ①훅("The Canon everyone knows — sung, not played")
                ②작곡가·곡명 · 고대비 · safe zone(하단15%·우측10% UI 회피)
                ※소리끄고 봄 → 텍스트 필수(무음+무텍스트 = "아무일 없음")
루프            마지막 음 → 첫 음 (리플레이=최강 신호 · >75%유지 ~3배 push)
마지막 2s       CTA "Full a cappella version → on the channel" + 명화 full reveal
```

**왜 이 포맷**: (a) 3초 훅 (b) 루프 친화 (c) *이미 렌더된 롱폼 오디오+명화 재사용* → 제작 ~20~30분 (d) 완전 온브랜드 → 미스매치 청중 안 들임 (e) §2가 증명한 수동 다리(CTA+핀링크) 내장.

**금지**: "못 부르는 척 reveal"·코미디·프레네틱 밈 = 톤 부적합 + 롱폼 AVD 희석.

## 4. 퍼널 다리 (수동 · 필수)

1. **마지막 2s 온스크린 CTA** → "전체 버전은 채널에".
2. **고정댓글 즉시** = 롱폼 직링크 1줄("Full version here ↳"). (핀링크가 standalone 대비 전환↑ [미검증·방향].)
3. **발행 타이밍** = 롱폼 공개 *직후*(목적지 존재). 성장판이면 7일 뒤 다른 악구로 2편째(staggered 10~14일).
4. 제목 = 별명 forward("Pachelbel's Canon — the part you know · Miku a cappella").

## 5. 측정 (퍼널이 *작동하는지*)

- ❌ raw 쇼츠 뷰·구독 (스와이프 허영지표)
- ✅ **Studio 트래픽소스 "Shorts feed" → 롱폼 뷰/구독이 실제 상승했나** + 종료화면/CTA 경유 전환
- 실험 단위 = **4~6편** 돌리고 scale 결정. (현 shorts_first_proof workflow를 *측정 게이트* 중심으로.)

## 6. 리스크·중단 기준

- **유지율 희석 = 핵심 리스크**: 우리 edge는 깊이(60% AVD). 스와이프 구독자가 롱폼 AVD·구독품질 끌어내림.
- **결정룰**: off-brand 기믹 필요하면 만들지 마라 / 렌더 자산에서 ~30분 내 온브랜드 못 만들면 기회비용 과다 / **다음 롱폼이 더 복리일 수 있음**.
- 저작권: PD 작곡 + 자작 보컬로이드 = Content ID 클레임 위험 없음. 명화 PD만 재확인. Topic 채널 = 배포사 안 거치는 직접 업로드라 안 생김(안전 [추론]).

## 7. R&D 제언 (타이밍)

두 길 — 코튼 결단:
- **(가) 지금 파일럿**: 이미 발행된 인지도 강곡(캐논)으로 쇼츠 1편 실험 → 퍼널 측정. 콜드 유입을 빨리 연다. 단 카탈로그 얇음.
- **(나) 카탈로그 먼저**: ②인지도 웨이브 2~3곡 더 쌓아 *떨굴 자산*을 두껍게 한 뒤 쇼츠 시작. 리서치 C의 "쇼츠는 카탈로그를 증폭" 정합.
- **MOKA 기울기**: (나)에 약간. 8편 카탈로그 + off-brand 위험 + 1인 제작시간 고려 시, *인지도곡 몇 개 더 + 그 중 가장 쇼츠훅 강한 곡(예 산왕의 궁전·캐논)으로 1편 파일럿* 병행이 균형. 단 약한 기울기 — 코튼 큐레이션.

## 8. 정직 플래그
- 퍼널 % 수치 거의 다 마케팅 case study = 방향성만(롱폼 3~4배 우위 비율만 일관).
- 홈피드 롱폼 축소(2025-12) [미검증·creator 관찰] — 사실이면 쇼츠 가치↑이나 확정 아님.
- 쇼츠는 1인 제작시간 = 다음 롱폼과 기회비용. R&D 단계 = *실험*이지 cadence 약속 아님.

## 9. s403 (2026-06-06) — 2층 콘텐츠 전략 + 세로 비주얼 방향 (디스코드 R&D)

> §1~8(s402)이 *왜·언제·측정*이라면, 여기는 *서브 영상 전체의 위상* + *세로 화면을 어떻게 짜나*. 코튼 확정 항목과 R&D 갈림길 구분 표기.

### 9.1 2층 콘텐츠 전략 (코튼 확정)
- **본진(현 8편) = 원작충실·점잖음 = 무결성 담당.** 함부로 자르거나 과장 못 함.
- **서브(쇼츠·합본 등 가공물) = on-brand 어그로 = 유입 담당.**
  - **쇼츠 = 콜드뷰어 획득.** 목적 = "유명곡을 *미쿠로만* 구현하는 채널이 있다"는 인지 살포. 코튼 목표 cadence = **주 2편**.
  - **합본 = 핫뷰어 공급.** 본 영상을 추려 이미 관심 있는 사람에게 콘텐츠 제공(예 8곡 하이라이트 메들리).
- **MOKA가 명시한 이 전략의 선물**: 충실성 부채를 본진이 다 짊어지므로 **서브는 본진이 못 치는 장난(발췌·배속·자막·후킹)을 칠 자유**가 생김.
- **단서(on-brand 못 박음)**: 서브 어그로가 본진 톤과 어긋난 싸구려 밈베이트면 콜드클릭은 터져도 점잖은 6분 풀곡 앞에서 튕겨 = *깔때기 샘*. 건전 어그로 레버 = **스펙터클(N미쿠 떼창)·인지 도파민(아는 소절 0.5초)·경이(명화가 노래/보컬로이드 한 명이 아니다)**.

### 9.2 콜드뷰어 0.5초 더블샷 (전제)
콜드뷰어용이라 첫 0.5초가 동시에 두 발: **①인지 타격**(유명 멜로디) + **②차별점='미쿠로만' *시각* 증명**. ②가 핵심인데 **소리로는 안 보임**(무음 스크롤). → 세로 화면이 곧 *획득 레버 자체*. (§3 텍스트 번인 정합 · 여기선 "미쿠임을 0.5초 시각 증명"으로 한 겹 더 좁힘.)

### 9.3 세로 비주얼 3방향
- **A. 합창단 벽 (N-미쿠 스펙터클)**: 세로 풀블리드에 미쿠 다수 떼창 대형(사탕요정 N=32 재활용). ②를 *물량*으로 증명 최강. 약점 = 다미쿠 세로 아트 곡별 제작비(템플릿화 필수).
- **B. 명화가 노래한다 (Living Painting)** ← **MOKA lean(척추)**: 기존 1:1 명화 커버를 세로 풀블리드 크롭, 딱 하나 움직이는 게 미쿠 입/미세모션. 비용 거의 0(LOCK 커버 재활용) + **본채널 브랜드 다리 최강**(같은 커버 언어 → 콜드뷰어가 본진 가도 톤 일치 = 깔때기 안 샘). 약점 = 떼창 스펙터클 약함(오디오 다성 + 캡션으로 보완).
- **C. 성부 분해 / 카운터 (텍스트 어그로)**: "🎤 미쿠 ×32" 카운터·성부 스택·"One vocaloid. Every voice." 자막. ②를 *글자로* 못 박아 무음 명시력 최강. 약점 = 텍스트 의존 = 점잖은 톤에서 가장 멈·브랜드 다리 약함.

### 9.4 MOKA 베팅 (R&D 제언 · 코튼 결단 대기)
**기본 템플릿 = B(명화구동) 척추 + 캡션 한 줄(C 양념) + 사탕요정류 高N 곡은 A(다미쿠) 변주.** C 단독 X(톤 깨짐). 근거 = B가 비용0 + 브랜드 다리 최강이라 깔때기 안 샘 + 약점은 캡션·오디오·A변주로 메워짐.

**다음 세션 재개 갈림길**: 척추를 **B(명화구동·MOKA lean)** vs **A(스펙터클 기본)** 중 무엇으로 둘지 코튼 결단 → 확정 후 *반복 가능한 쇼츠 파이프라인 1개*(산출물 = 쇼츠 1편 아님)로 구체화. 첫 곡 = §7·s402 후보(짐노페디/조플린 노출리더 또는 캐논).

## 10. s404 (2026-06-07) — 쇼츠 시리즈 **제목 컨셉 확정** (밈 결합 · 디스코드 R&D)

> §9가 *비주얼 척추*라면 여기는 *시리즈 네이밍·밈 결합*. 코튼 발의("클래식을 미쿠에 싸서 드셔보세요") → 후보 발산 → 재미 최우선 결단 → 단일안 LOCK.

### 10.1 확정 (코튼 LOCK)
```
제목: 클래식을 미쿠에 싸서 드셔보세요 #
부제: [곡명]
```
- 넘버링 = `#{회차}` (또는 `#3 — 백조의 호수`처럼 부제 곡명 병기).
- **밈 뿌리**: "XX를 김치에 싸서 드셔보세요" 템플릿. 원본 = 2013-10-19 KBS 연예가중계, 리포터 김앤젤라가 톰 행크스(캡틴 필립스 홍보) 인터뷰 중 스팸 얘기에 무표정하게 *"스팸을 김치와 드셔보세요"*. 웃음 DNA 3 = ①무표정 진지("정석입니다") ②**한국인이 외국인에게 '제대로 먹는 법'을 가르침** ③대상 불문 universal 템플릿 × 부조화. (코튼 컨셉은 김치→미쿠 / 음식→클래식 슬롯 치환 + 'Korea teaches the world' 프레임이 Muse와 정합.)

### 10.2 선정 과정
후보 발산(MOKA 10 + Gemini 리서치 10) → 코튼 6 finalist → **"재미를 최우선으로" 결단** → 김치밈 단일안 LOCK.
- **기각된 강후보**: `Classical Music A Cappella (Miku's Version) #`(글로벌·durable·brand-safe·USP증명 최강이나 **clever ≠ funny** — 폭소 아님) · `Sacrilegious Miku's…`(TwoSet층 정합·글로벌 엣지나 casual에 '진짜 불경'으로 부정독해 위험) · `미쿠 팬의 클래식 소비법 #`(KO durable이나 특정 밈 뿌리 약).
- **김치밈이 이긴 이유** = 6개 중 **재미 1위**(레퍼런스 몰라도 부조리가 터짐 · Sacrilegious는 TwoSet 알아야 웃김) + 하이로우 갭 최강.

### 10.3 받아들인 트레이드오프 (조용히 안 넘김)
1. **KO 천장** — 글로벌 깔때기는 포기(재미 우선의 대가).
2. **제목=메타포 → USP를 글자로 증명 X**("싸서"가 '미쿠 목소리만/아카펠라'를 직접 말 안 함). → **첫 0.5초 화면(명화 미쿠)+소리(아카펠라)가 자동 증명.** 제목은 웃기는 일만, 증명은 영상이 떠맡는 분업(§9.2 더블샷 정합).

### 10.4 ★ 교훈 = 쇼츠 텍스트 2층 분리 (MOKA 자가결함 발화)
- **A층(시리즈 래퍼)** = 내구성·넘버링·식별. **B층(첫 0.5초 훅 자막)** = 폭소·어그로, 회차별 교체.
- MOKA가 *단일 제목 하나로 '재미'+'시리즈 효율' 동시 짜내기*를 무리하게 밀다가, 최적화 타겟이 **'재미'(코튼 씨앗 가치) → 'brand-safe·durability'로 조용히 강등**됨 (코튼 *"최종안이 재밌게 느껴질 것 같아?"* 한 줄이 적발). → 2층 분리로 정정.
- 이번 결단 = 재미 최우선 단일안 → 김치밈 제목이 사실상 B층(폭소)을 떠맡고, A층 기능(내구성·넘버링)은 `#회차` 표기가 최소 충족. 향후 글로벌 트랙이 필요해지면 A층(예 Miku's Version 래퍼) + B층(회차 밈자막) 분리 구조를 별도로 둘 여지 보존.
