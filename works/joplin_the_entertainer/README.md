## 결단 자료 (s326 · 코튼 *기초 체력 다지기* axis 정합)

- **곡 선정 path** = 작은 별 변주곡 K.265 drop (코튼 *생각보다 범위가 너무 커져서* 자가 결단 · 12 변주 ~12분 scope) → 5분 이내 곡 재선정 cycle 진입. 환희의 송가 4악장 발췌 axis 검토 통과 후 *arrangement 진입 의제* 박힘 → 코튼 자가 *완벽주의 risk + 기초 체력 우선* 결단 = ragtime 솔로 피아노 path 정합.
- **분량** = 통째 ~3:30-4:00 (발췌 없음 · 짐노페디·비발디 family 정합 = 자연 짧은 곡 통째 transcription default).
- **acappella 양식** = 2층 명확 분리 (RH 싱코페이션 멜로디 + LH stride bass) · 미쿠 layer 3-4개 자리 (Lead + Bass + Mid 1-2). 짐노페디 (1-2 layer) + 비발디 (5-6 layer) 사이 점층 정합.
- **명화** = Seurat *The Circus* (1891) · 르네상스 후 신인상파 첫 진입 자리. 점묘 + 서커스 흥 = ragtime 흥 정합 (csv 매칭 사유 그대로).
- **score** = `planning/candidates_opus/조플린_ 디 엔터테이너.pdf` 이미 박힘. IMSLP `https://imslp.org/wiki/The_Entertainer_(Joplin,_Scott)` 자료 풍성.

## ragtime 양식 신규 challenge 자료

이전 두 곡과 결 다른 자료들 (기초 체력 axis 정합):
- **syncopation 정밀도** — RH 16분 syncopation · V6 timing 빡빡한 통제 필요
- **stride bass on voice** — LH oom-pah/walking 베이스를 미쿠 저음 layer로 = 양식 자체엔 unusual
- **2층 텍스쳐 통제** — 짐노페디(legato 단선) → 비발디(ensemble polyphony) → ragtime(2층 명확 분리) 흐름 정합
- Joplin 자가 indication = *"Notice: Do not play this piece fast"* (악보 첫 머리) · 양식 straight-time keep (swung X · 코튼 본격 작업 시 자가 결단 자리)
