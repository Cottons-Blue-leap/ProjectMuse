## 솔로 피아노 양식 자료

- **2-layer texture** — 원곡 = RH bel canto 멜로디 + LH waltz-like arpeggio. 6 voice 분배 axis = lead_miku (멜로디) / mid_oo (arpeggio inner harmony) / low_oo (베이스 hint) / halo_high (lyrical sustain) / air_mm (작은 glue layer) / lead_double (조용한 정체성 보조). 짐노페디 3성부 sparse base 통과 → 쇼팽 5~6성부 fuller texture axis (단 ornamental flourish 자체엔 lead_miku 단독 axis · 화성 simple keep).
- **ABA' 양식** — 12 마디 A (단순 멜로디) + 12 마디 B (변형 + emotional crescendo) + 12 마디 A' (ornamental flourish + coda). 변주 양식 자료 (작은별 K.265 12 변주 양식과 다른 *단일 변주* axis · 콤팩트 axis 정합).
- **ornamental flourish 양식** — A' coda 자료 ornamental flourish (32분 음표 fluid passage) = V6 양식 challenge 자료 axis · 코튼 결단 자리 (omit / 단순화 / 그대로 keep).
- **bel canto 양식** — 이탈리아 오페라 콜로라투라 영향 · *legato + portamento + 자유 rubato* axis. 미쿠 voice *legato sustain* 자료 정합 강 (그리그 plaintive 목관 axis 비교 양식 차별점).
