## A. 경쟁·벤치마크 (similar channels)

**핵심**: 이 채널은 *3중 니치 교차*(보컬로이드 커버 × 아카펠라/보컬 레이어 × 명화 클래식). **정확히 일치하는 채널 없음**(미검증 아닌 확인결과 — 타겟 검색이 공식 미쿠 채널만 반환). = 화이트 스페이스(기회) + 수요 신호 없음(리스크) 양면.

축별 comparable:
- **아카펠라 축 (제작방식 최근접)**: Peter Hollens(~7M·주간 cadence+협업), Geoff Castellucci(자기 목소리 멀티트랙 = 미쿠 멀티트랙과 최근접·시그너처 훅[극저음]으로 reaction/clip 바이럴), MAYTree(~6.4M·**쇼츠/바이럴 클립**이 발견 동력). → [추론] 작은→큰 성장은 **단일 반복 시그너처 훅** + **협업**이 동력이지 카탈로그 볼륨 아님.
- **명화+클래식 축 (패키징)**: HalidonMusic·"TV Art" 류 = 명화가 곧 썸네일(samdoesart 패턴) + 재생목록/컴필레이션. **단** 이들은 1~5시간 배경음 루프 = *다른 소비 모드*(능동청취 아닌 배경). 우리 3~6분 단곡은 부분적으로만 전이. [추론]
- **보컬로이드 클래식/아카펠라 축**: 확립된 채널 **확인 불가** = 진짜 빈 레인.

**발견 메커니즘 (작은 채널 2025-26)** [확립, 다출처]:

- **3개 분리 알고리즘**: 검색(메타+시청이력) / 홈·브라우즈(브라우징패턴) / **쇼츠(별도 시스템·완성률 최적화)**.

## B. 검색·SEO (2025-26)

> 전제: YouTube는 검색 랭킹 메커니즘을 거의 공개 안 함. 공식(support.google)은 l10n 존재만 확인·알고리즘 무설명. 대부분 [추론=업계 합의]. % 수치는 마케팅 주장.

**제목 토큰 우선순위 (front→back)** [확립 규칙 + 추론 적용]:
작곡가 성 → **대중이 실제 치는 별명/incipit** → "A Cappella" → "Hatsune Miku / Vocaloid V6"(라틴 기본, `初音ミク`는 ja 로케일+태그) → 카탈로그 번호 맨 뒤.
- 별명 >> 카탈로그 번호 [확립 행동]. "Moonlight Sonata"로 검색하지 "Op.27 No.2"로 안 함. **우리 실측 쿼리(salut d'amour, ah vous dirai-je maman)가 incipit 검색을 증명**.
- 60~70자 이내(모바일 truncation 방지). 버전 수식어 1개만.

**태그·설명** [확립]:
- 태그 = 여전히 minor 신호(분류·오분류방지). **10~15개·첫 태그=정확한 곡 문자열 verbatim**. 우리 실측 쿼리가 곧 태그 리스트.

- 해시태그: **첫 3개가 제목 위 렌더**. **3~5개·>15개면 전부 무시**. 예 `#HatsuneMiku #Vocaloid #ClassicalMusic`.
- 고정댓글 = SEO 가치 없음, engagement/retention 표면(우리 doctrine = engagement 용도로 정확).
- **랭킹을 실제 움직이는 건 유지율·시청시간·CTR·2025 "만족도" 신호** — 메타데이터 아님. 메타는 *매칭*(올바른 풀에 진입), 랭킹은 *행동*이 결정. → **검색이 작지만 최고유지율인 우리 상황은 전략적으로 유리**(알고리즘이 보상하는 바로 그 신호). 검색 발견성 강화가 옳음.

## C. 쇼츠 퍼널 (2025-26)

> % 수치는 거의 다 3rd party 집계·변동 큼 = 방향성만.

**퍼널은 자동이 아니다** [확립·다출처 합의 = 가장 중요]:
- **쇼츠 피드 ↔ 롱폼 추천 시스템은 작동상 분리.** 쇼츠 바이럴이 같은 시청자에게 롱폼을 자동 노출 **안 함**. → **다리(bridge)를 수동 설계해야**(고정댓글 링크·온스크린 CTA·채널 레이아웃·핸드오프).
- [추론·부분상충] 쇼츠 시청은 채널레벨 양성신호라 *modest*하게 롱폼 추천 확률↑ 가능. 의존 X.

**전환** [방향성만]: 롱폼이 시청자당 **~3~4배** 구독전환 우위(쇼츠 0.8~5% vs 롱폼 2.3~15%, 출처 불일치하나 *비율*은 일관). 쇼츠 = top-of-funnel 발견 표면이지 구독 머신 아님. 12구독 채널엔 *적당한 쇼츠 도달(수천뷰)도 현 노출의 큰 배수*.

**작동하는 음악 쇼츠 포맷**:
1. **"누구나 아는 그 부분" 훅** (최고 레버) — 가장 인지되는 악구로 *콜드 오픈*. 인트로/로고 X. 첫 3초에 50~60% 이탈하므로 0:00에 명곡 악구 hit.
2. "Name that tune" 몽타주 — 채널레벨 쇼츠용(곡별 아님).
3. **만족 루프** — 마지막 음이 첫 음으로 흐르게. 리플레이=강한 바이럴 신호(APV>150%, >75% 유지 → ~3배 push). 짧은 악구(15~25s)가 루프 잘 됨.
4. **명화 reveal** — 디테일→전체 페인팅을 음악 swell에 싱크(우리 차별점).
5. **티저+릴리즈 날짜 텍스트** — 퍼널 라우팅 1차 목적 포맷.
6. **회피**: "못 부르는 척 reveal"·코미디·프레네틱 밈 = 톤 부적합 + 미스매치 청중.

**cadence·제작**:
- 1롱폼+2~5쇼츠/주가 AI보조 상한. **우리 = 1쇼츠/릴리즈 하한, 2~3쇼츠 10~14일 staggered가 성장판**(자기경쟁 회피).
- 길이 sweet spot 15~35s, 단일 악구 루프는 **18~25s**. 평균 완성률 ~73%·바이럴 ~76%.
- 9:16 1080×1920. **명화(16:9)를 9:16로 크롭해 구도 잃지 말 것** → 9:16 프레임 중앙에 명화 + 보완 블러/레터박스(채널 레터박스 미감 유지). 텍스트는 safe zone(하단 ~15%·우측 ~10% UI 가림).
- **소리 끄고 봄** → 번인 텍스트 필수(악구+곡명+훅, ≤2줄, 고대비). 무음+무텍스트 = 첫 3초에 "아무 일도 안 일어남"으로 읽힘.
- **오디오 저작권 clean**: PD 작곡 + 자작 보컬로이드 녹음 → 3자 master/composition 저작권 없음 = Content ID 클레임 위험 없음. (잔여 벡터=명화가 진짜 PD인지만 확인.) 비상업 미쿠 사용 = Crypton 약관 내. YPP 수익화 nuance·Topic 채널은 [미검증]이나 *배포사 거치지 않는 직접 업로드는 Topic 안 생김* = 안전 [추론].

**리스크 (이 브랜드에 쇼츠가 해로운 때)** [확립·sourced]:
1. **청중 미스매치** — 톤 안 맞는 바이럴 쇼츠 구독자는 롱폼 무시/이탈 → 롱폼 AVD 끌어내림. 차분·고크래프트 브랜드에 코미디 쇼츠 = 역효과.
2. 저품질 구독/허영지표 — sub 카운터만 오르고 engaged 청중 안 늚.
3. **유지율 희석 = 핵심 리스크** — 우리 edge는 *깊이*(60% AVD). 스와이프 시청자 유입이 바로 그 신호를 약화.
4. 기회비용 — 쇼츠 1편 = 다음 롱폼 제작시간.
