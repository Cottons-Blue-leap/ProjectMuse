## 해석 (객관 축 + 코튼 게이트 분리)

### 1. 라우드니스 — 게인업 필요 (1차 렌더 전형)
−22.4 LUFS는 채널 친밀곡 밴드(−16.5~−17)보다 ~5.5dB 낮음. 쇼팽 1차본 −22.1과 동일 패턴 = 게인업 재익스포트 권고. TP −5.8로 헤드룸 충분.
- **클린 게인 +4.8dB → −17.6 LUFS** (TP 정확히 −1.0 · 무리밍 · Gymnopédie −17.5 군집)
- **−17 목표 = +5.4dB → TP −0.4** (천장 초과 0.4dB → 피크 약한 TP리미팅)
- **−16.5 목표 = +5.9dB → 약 1.1dB 리미팅**
- crest 19.7 높음 = 피크가 RMS 대비 멀리 떠 있음 → −17 이상은 게인+TP리미터(크레스트 보존, LRA 깎지 말 것).

### 2. 음색 = 어둠/따뜻함 — ⚠️ 코튼 귀 게이트 (E34 교훈)
2k 이상 1.2%는 측정상 극단적. **단 이를 "밝기 부족=결함"으로 프레임하지 않음** (⑪ 하이든 E34 = warmth를 어둠=결함으로 오독한 전례). 첼로 솔로+Ah 모음+pp 정적곡 = 본질적으로 어두움이 정상. 판단은 코튼 청취:
- 편곡 게이트 ②「물결 셰머」= 아르페지오 일렁임이 이 어둠 속에서 *살아 있는가*, 아니면 베일에 가려 둔탁한가.
- warmth가 의도대로면 그대로 keep. 셰머가 죽었다면 그때 presence/air 미세 조정.

### 3. 클린 항목
클리핑 0 · DC 0 · 포맷 정상 · 위상 양호(corr 0.948) · 스테레오 친밀 센터 = 솔로 성격 정합. 손댈 것 없음.

### 판정 (객관 축)
1. **"첼로 묻힘" = 의도대로 개선됨 (방향 확정).** 재익스포트가 250-500 반주 머드 밴드를 −6.3pt 솎고, lead 노래선이 사는 1-2k를 +7.2pt 들어올림. = 리드를 마스킹하던 반주층을 줄이고 리드 register를 부각 = 정확히 "덜 묻히게" 하는 변화. air/brightness 부풀림 아님(2k↑ 거의 불변) → E34 톤 함정 회피, 순수 균형 재배치.
2. **단 하드클립 결함 = 필수 수정.** TP +0.0 / 풀스케일 2샘플. test3 트림 전례와 동일 패턴 = **−1.0dB 출력 트림 → 약 −17.2 LUFS / TP −1.0** (새 균형 100% 보존, 선형 게인이라 스펙트럼/crest 불변, 클립만 제거). 친밀 밴드 유지 + 구 마스터보다 여전히 큼·앞섬.
3. **balance "정답" 판정은 코튼 청취 게이트.** test3는 이미 청취 통과한 LOCK본 = "결함이라서 바꾼다"가 아니라 코튼 귀의 균형 선호. MOKA는 변화가 의도(리드 부각)대로임을 계측 확인까지만.
