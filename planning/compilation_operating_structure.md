## 2. 합본 vs 재생목록 판단 룰 (핵심)

둘은 경쟁이 아니라 **다른 일을 한다.**
- **재생목록** = 비용 0 · 새 영상 0 · watch-time을 *개별 영상*에 적립(개별 알고리즘 신호 강화) · 이미 온 시청자 회유. 약점: 노출/검색이 약해 신규 진입을 거의 못 만듦.
- **합본** = 새 단일 영상 = 새 노출 표면 + 새 썸네일/제목으로 *새 검색어*를 잡는 **신규 진입점**. 약점: 제작 비용 + 중복/잠식 위험.

> **판단 기준:** "이 묶음에 **고유한 검색 수요 + 완결성(하나의 작품/사이클)**이 있나?"
> - **YES → 합본** (단일 작품으로 재포장 = 새 진입점 + 원곡 청취경험 복원)
> - **NO → 재생목록** (비용 0, 개별 신호 적립)

적용:
- "사계 봄 1~3악장" → 합본 ✅ (봄 = 완결 단위 + "비발디 사계 봄" 단일 검색어)
- "사계 전곡" → 합본 ✅✅ ("비발디 사계" 거대 검색어)
- "작곡가별"(쇼팽 모음·바로크 모음) → 재생목록 ❌ (느슨 · 고유 검색수요/완결성 없음)
- "쇼팽 녹턴집(21곡)" → 재생목록. 합본 한다면 Quest가 아니라 **"쇼팽 녹턴 베스트" 선별 합본**(Flagship/Evergreen 성격). Quest = 끝선 명확한 완결 사이클(호두까기·사계)에만.
- "전곡 쇼케이스(미쿠가 부른 전곡 Vol.1)" → **재생목록**. 느슨한 전곡 묶음·완결성 없음 → 이미 `Miku Non Stop A Cappella` 재생목록이 lean-back 연속재생 역할 수행. 합본 X (2026-06-11 코튼 적발 · MOKA 초기 추천 자가 철회). 선별 베스트가 필요하면 Flagship 10선이 담당.

**다악장 운영(코튼 결정 2026-06-12):** 개별 악장 + 합본 둘 다(사계 봄 1악장 이미 개별 발행과 정합). 잠식 완화 = 합본을 **"전곡 완성 보너스"로 마지막에** 얹고(= 잠식이 아니라 완성 마일스톤), 개별↔합본 카드/설명 상호링크로 트래픽 환류.

### 무드 임계 트래커 (Evergreen — #1 발행은 10~15곡)
- **밤/고요**: ①⑥ + ⑩(겸) = ~2-3곡

## 4. 선곡 전략 시사점 (빈 슬롯이 다음 곡을 가리킨다)

멀티슬롯 효율로 다음 편곡 후보를 줄 세우면:

1. **비발디 봄 2·3악장** = 첫 Quest 깃발을 가장 빨리 띄움. 2곡이면 "**사계 봄**" 합본 완성(완결 단위+단일 검색어) + 사계 전곡 진행 + 봄/희망 무드 + 바로크 = **4슬롯**. → **첫 작품집 합본 1호 유력 후보.**
2. **꽃의 왈츠(호두까기)** = 호두까기 Quest + 차이콥스키 + **겨울 무드(현재 1곡뿐)** + Flagship 후보 = **4슬롯**. 가장 빈약한 겨울 무드를 메우는 최고 효율.
3. **겨울 보강** = 겨울 무드가 ⑧ 단 1곡 → 비발디 사계 겨울, 차이콥스키 겨울 곡 등이 Evergreen "겨울" 시리즈를 빠르게 임계로.

> 원칙: "다음에 뭘 편곡하지?" → "**어느 빈 슬롯을 메우면 가장 많이 채워지나?**"
