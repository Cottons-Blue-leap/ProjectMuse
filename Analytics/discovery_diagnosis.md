## 4대 원인 (인과 체인)
1. **검색 발견의 역선택** — 태그가 곡보다 도구(V6)를 강하게 신호 → 우리가 이기는 검색어가 *저볼륨 + 의도불일치*인 도구 검색뿐. 들어와도 35초 이탈(검색 유입 평균시청 최단 = 이 미스매치의 지표). 이탈이 알고리즘에 나쁜 신호.
2. **고볼륨 곡명 = 권위 부족으로 묻힘** ("canon in d" 1뷰). 단 **저경쟁 롱테일은 잡힘**("salut d'amour" 3뷰) = 공략 틈.
3. **일본 검색 미진입** — JP 11뷰는 전부 추천 유입, 검색 1뷰. 제목 일본어화 ≠ JP 검색행동(初音ミク アカペラ / ボカロ クラシック) 공략.
4. **추천 의존 + 콜드 CTR 악순환** — 추천 비중 59.8%→39.9% 하락, 구독피드 14%→31.4% 급등 = '발견형→유지형' 닫힌 고리. 콜드 노출 CTR 0.6%가 확산을 끊음.

**한 문장:** 품질이 아니라 *메타데이터 설계* 문제 — 발견의 입구가 잘못된 문(도구)에 나 있고 맞는 문(곡·일본 니치)엔 안 나 있음. 직접 고칠 수 있는 영역.

## 실행 후보 (보류 — 측정 더 쌓은 뒤)
1. **태그 재설계** — 도구 키워드(vocaloid6/V6) 비중↓ + 감상 의도·저경쟁 롱테일(relaxing classical / miku classical / study·sleep / 곡명+무드)로 재배치. 'salut d'amour' 패턴 의도적 복제.
2. **일본 니치 공략** — 初音ミク アカペラ / ボカロ クラシック / 初音ミク クラシック 정조준.
3. **곡 선정의 검색 전략화** — 저경쟁 × 인지도 곡 우선(⑩ 울게 하소서가 후보 성격).
