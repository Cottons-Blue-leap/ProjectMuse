## 5축 정합 자료

### ① s356 자기비판 직격 응답 axis 매우 강

- 코튼 자가 적발 = *팬덤은 아카펠라 크게 원함·명화 관심없을걸*
- Mini Miku Choir = *캐릭터 = 음악 시각 anchor* 양식 = 자가비판 정면 응답
- 명화 hero 양식은 *음악 외적 anchor*였음. 캐릭터 hero = *음악 자체 시각화* 직격.

### ② content.png 자체 production 강 · 1차 도입 부담 매우 낮음

- 이미 *Hero + 8 animation + 6 voice-part variants* 자료 박혀있음. 시각 자료 결단 자리 95% 통과 자료.
- 코튼 직접 시각 검증 통과한 자료 (이 정도 톤 정합 + 클래식 atelier 본질 안 깨짐).
- 8 animation set + 6 voice-part = recolor/ribbon variation 양식 = 자료 production *작은 비용* axis.

### ③ 음악 시각화 본질 = 캐릭터 1:1 매칭이 가장 깔끔

- 6 역할 taxonomy 시각 매칭 자료. 시청자가 *지금 어느 성부 들어오는지* 시각으로 즉시 이해.
- 짐노페디 3성부 sparse → 3 캐릭터만 active · 비발디 ensemble → 5~6 active · 자가 조절 axis.
- v1~v6 mockup들이 *명화는 정적* 약점 자가 누적 → Choir는 *성부 진입 timing = 캐릭터 활성* 양식으로 *동적* 본질 직격.

### ④ 클래식 아틀리에 톤 완전 정합

- content.png 자체엔 *작고 단순한 클래식 데포르메 미쿠* = 코튼 우려 (캐릭터=모에 양식 risk) 사전 차단 자료.
- *Readable silhouette · Warm & classical · Timeless atelier feel* axis = 1년 작전 자가 분기 risk ↓.

### ⑤ AI-인식 risk 자가 점검 통과

- 자가 적발한 risk = *결국 AI 양식* 표면. 본 양식 자체엔 **약화 매우 강** 자가 평가:
  - 클래식 데포르메 양식 = *AI cover 표면* 안 닿음 (AI cover = realistic 양식 default · chibi atelier는 *손그림 stylized* 양식 인식)
  - 미쿠 의상 통일성 (*Classical Miku* lock) = *자료 일관* 표면 강 = AI 즉흥 생성 양식 X 양식
- 단 본 axis 자가 확신 70%. 코튼 자가 시각 검증 axis 의제 keep.

## 코어 의제 7건 자가 발화

### ① 대파 path vs Mini Miku Choir path · 갈림

- 둘 다 *캐릭터=hero* 양식 정합. 결단 자체엔 충돌.
- **네기 path** = AI-cover 인식 risk 0 + 팬밈 인사이더 + 라이선스 통째 우회. *유쾌* axis.
- **Mini Miku Choir** = 정체성 직설 + No-AI 쐐기 약화 risk (AI 생성 캐릭터 → "결국 AI 양식" 표면) + Crypton Piapro 양식 fully 정합. *정제* axis.
- **synthesis 의제**: 둘 합칠 수 있나? (대파 SATB ensemble = Mini Negi Choir / 미쿠는 hero pose 단일 + 6 네기가 voice part 분담?) 자료 자리 axis.

### ② 명화 자리 재정의

- 시그너처 5축 ④ *명화+미쿠 녹여내기 미학*. 캐릭터=hero 양식 진입 시 명화는?
- (a) letterbox만 (현 양식 keep · 색조 그라데이션 자료) / (b) 배경 layer (캐릭터가 명화 위 올라타기) / (c) cover 이미지에만 (영상 본문엔 등장 X · intro/outro만) / (d) 폐기
- 코튼 결단 자리.

### ③ 6 역할 taxonomy 충돌 점검

- 현 양식 (project_muse.md §6 역할): `lead_miku · lead_double · halo_high · mid_oo · low_oo · air_mm`
- feedback 양식: `Soprano · Alto · Tenor · Bass · Mezzo · LowBass`
- → **음악 production axis** (현재 양식 keep) vs **시각화 표면 axis** (SATB 양식 채용) 분리 가능 axis. 별 layer.
- 단 *6명 캐릭터 = 6 역할 1:1 매칭* 자가 발화 axis. lead_miku=Soprano? halo_high=Mezzo? mapping table 의제.

### ④ MIDI/MusicXML-driven animation 실현성

- feedback 방법 3 = *장기적으로 가장 좋음* 자가 추천.
- ⚠️ **현 워크플로우 정합 X 자가 적발**: s302 리팩토링에서 *PDF + V6 직접 입력 path · MusicXML/auto_midi 자료 통째 폐기* 결단. project.json에서 `auto_midi · render_ready_midi · vocal_plan` 키 폐기.
- 재발 의제: V6 → MIDI export 가능 검증 (Vocaloid 6 Editor 기능 자가 확인) · 가능하면 *render 후 산출 자료* axis path · workflow 부담 elevation 회피 보장 의제.
- **fallback** = 방법 2 (Audio amplitude 자동 연동 · stem 분리 자료 이미 확보) · Remotion Web Audio API로 충분.

### ⑤ 8 animation set × 6 캐릭터 = 48 asset minimum

- feedback 본질 = *처음부터 많이 만들 필요 없음*. 1 캐릭터 8 pose만 신축 → 6 voice-part = recolor/ribbon variation으로 확장 (content.png 자체엔 정확히 이 양식).
- 실 제작 의제: AI 이미지 생성 양식 (Crypton Piapro 일러스트 라이선스 axis · CC BY-NC + AI 생성 약관 자가 점검 의제 자리)
- Remotion 구현 = Lottie / 8 frame sprite / each layer keyframe 양식 axis. 도구 결단 별 cycle.

### ⑥ 시선 분산 vs 음악 집중 axis

- feedback 자체엔 *과하게 움직이는 게 아니라 자기 성부가 들어올 때만 살아나는 방식* 본질 자가 보호.
- 단 6 캐릭터 = 시청자 시선 multi-target risk. 짐노페디 3성부 sparse texture 양식에 6 캐릭터 = 4명 휴식 정합. 비발디 ensemble polyphony는 다 살아남 risk.
- 곡별 active 캐릭터 수 조절 axis 의제 (3성부 곡 = 3명만 등장 · 6성부 곡 = 6명 다).

### ⑦ 현 라이브 4곡 retrofit axis

- doctrine = *publish 통과 자료 retrofit X · 신규부터 default* (§시그너처 §3 v3 wordmark 양식 정합).
- 본 path 신곡 (⑤ 모차르트 5/28 예약 / ⑥ 그리그 setup) 진입 default 자료 자체엔 정합. Mozart 5/28 deadline 자가 발화 = R&D 결단 자체엔 본 publish 후 진입 path 자연 (현 cover_v1 양식 + scheduled · 변경 위험 elevation 회피).

## 네기 path · synthesis path 결단

### 네기 path = 별 트랙 자료 keep · 본 트랙 진입 X

- 강점 (라이선스 우회 + 팬밈 + 유쾌) 인정. 단:
- 신규 audience *왜 대파?* 진입 friction 자가 발화 (팬밈 인사이더 axis 자체엔 *팬덤 안* 인지도만 보장)
- 코튼 자가 unlock 본질 가치 강 → **스페셜 영상 / 시즌별 변주 / 100곡 마일스톤 영상 / Q&A** 양식에 자리 박음 path 추천 (자료 폐기 X)

### Synthesis (Hero=미쿠 + 6 네기 voice-part) = 거부 axis

- 코튼 s356 unlock 본질 = *미쿠=목소리, 대파=화신*.
- 네기가 voice-part 분담 = *대파가 미쿠 목소리 내는 양식* = 본질 양식 깨짐.
- 두 양식 다 *캐릭터=hero* 양식 자체엔 충돌 X 가능하지만 본질 양식 axis 자가 깨짐.
